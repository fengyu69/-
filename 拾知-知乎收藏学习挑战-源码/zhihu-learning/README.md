# 拾知：把知乎收藏变成 14 天学习挑战

可运行的中文 Web 应用 MVP，附 Chrome / Edge 浏览器扩展及自动化测试。前后端均为 JavaScript，后端使用 Node.js 内置 HTTP 服务与 SQLite，无需安装 npm 依赖或单独安装数据库。

## 快速启动

安装 **Node.js 22.13+（建议 24 LTS）**，解压源码包，在项目目录运行：

```sh
node --env-file-if-exists=.env server.mjs
```

浏览器打开 **http://127.0.0.1:8787**。Windows 也可双击 `启动拾知.cmd`。

1. 创建一个拾知账号（与知乎账号独立）。
2. 点击“体验摄影示例”，确认载入 30 条演示收藏；或通过扩展导入自己的收藏。
3. 点击“分析收藏并生成挑战”，默认自动为最集中的待学主题生成完整 14 天计划。
4. 每天精读、练习、写复盘，可上传作品；全部三项完成才计入完成天数。
5. 在设置中开启搭子匹配。另一个用户在同一服务注册并选择相同主题，即可邀请、接受和互评。

首次启动自动创建 `data/learning.sqlite`。关闭终端会停止服务，再次启动数据仍然保留。交付包不包含测试账号、密码、真实用户数据或 API 密钥。

## 已实现的功能

| 需求 | 实现 |
| --- | --- |
| 知乎收藏兼容 | MV3 扩展读取用户主动打开的收藏页；JSON 预览与授权导入；支持回答、问题及专栏文章原始链接 |
| 用户授权 | 扩展采集前确认、应用导入前确认、AI 传输另行授权、搭子匹配主动加入 |
| 分类 | 真正的大模型接口；无需密钥的本地关键词引擎；手动修正分类；搜索与筛选 |
| “一直想学”识别 | 收藏数量、已知收藏年龄、本应用挑战记录、自报学习状态共同判断，明确标注为推测 |
| 14 天挑战 | 自动从收藏中选文，每天精读、练习、复盘，带时间预算和原文引用；摄影有逐日具体课程 |
| 学习记录 | 持久化打卡、补记过去日期、作品图片上传、复盘校验、累计完成天数 |
| 学习搭子 | 多用户真实匹配、邀请与双向确认、主动共享打卡、作品互评、结束关系与屏蔽 |
| 撤回 | 清除本账号学习资料、计划、作品、相关关系与反馈，关闭 AI 和匹配授权 |

## 知乎导入操作

1. Chrome 打开扩展管理页，或 Edge 打开其扩展管理页，开启“开发者模式”。
2. 选择“加载已解压的扩展程序”，选择本项目 `extension/` 文件夹。
3. 在你自己的浏览器登录知乎，打开自己的收藏夹详情页，例如 `https://www.zhihu.com/collection/收藏夹数字ID`。
4. 点击扩展图标，勾选“这是我的收藏夹…”，点击“采集当前页面”。
5. **手动翻页或滚动加载后，再次点击采集**。扩展自动去重，可跨多个收藏夹累积，最多 1000 条。
6. 点击“导出 JSON”。回到拾知“导入知乎收藏”，选择导出的文件，查看预览并确认导入。
7. 导入后可清空扩展本地暂存，再采集下一批。每个拾知账号最多保存 3000 条收藏。

本实现采用“浏览器主动导出 → 用户授权导入”，**没有实现知乎官方 OAuth 登录或后台自动全量同步**。浏览器扩展不是知乎官方应用，不访问 Cookie、密码、浏览器内部状态，也不实现私有接口签名或自动翻页。`saved_at` 无法确认时保留 `null`，不会把导入日期冒充收藏日期。

兼容性边界：适配的是知乎网页端常见收藏列表 DOM（集中在 `extension/collector.js`）；不是知乎移动 App 内插件。本次未使用真实知乎登录账号进行实测，知乎改版、隐藏内容或未加载条目可能需要调整选择器。采集不到时扩展会明确报错；不会假装已经导入整本收藏夹。所有网页端文章内容以原始链接打开，不绕过付费或访问权限。

知乎有官方[数据开放平台](https://developer.zhihu.com/)。若后续取得应用权限，应以平台届时提供的 OAuth、收藏接口及授权范围替换导出链路；本项目不虚构未验证的接口参数。

### 导入数据格式

支持数组，或包含 `items` 的对象。必填 `title`、`url`；其他字段可选。

```json
{
  "version": 1,
  "source": "zhihu-visible-collection",
  "items": [
    {
      "title": "请替换为你收藏的文章标题",
      "url": "https://zhuanlan.zhihu.com/p/123456",
      "excerpt": "请替换为你有权导入的摘要",
      "author": "原作者",
      "collection": "摄影入门",
      "saved_at": null
    }
  ]
}
```

上面的文章链接仅示意格式，不是推荐阅读材料。`examples/photography-demo.json` 也是人工演示数据，链接为占位格式；应用会标注并禁止从演示条目跳转精读。原始链接作为用户内的去重键：重复导入保留首次导入条目，不覆盖手动修正。

## 配置真正的 AI 分析

复制 `.env.example` 为 `.env`，填写服务器持有的密钥：

```dotenv
HOST=127.0.0.1
PORT=8787
APP_ORIGIN=http://127.0.0.1:8787
AI_BASE_URL=https://api.deepseek.com
AI_MODEL=deepseek-flash
AI_API_KEY=在这里填写自己的服务密钥
```

重新启动服务器。在拾知“设置与授权”勾选 AI 分析授权并保存，再在分析或生成挑战时选择 AI 模式。

服务适配 `POST {AI_BASE_URL}/chat/completions`，使用 `response_format: {type: "json_object"}`；可改用支持同一协议的服务。模型名以服务商实际可用模型为准。参考 [DeepSeek JSON 输出文档](https://api-docs.deepseek.com/guides/json_mode/)。AI 使用可能产生服务商费用。

AI 分类按 40 条一批执行，发送标题、最多 600 字摘要、收藏夹名称和随机资料 ID。生成计划使用所选主题最多 80 条资料，每条最多 500 字摘要。仅以这些资料制定学习建议，不声称精读了未提供的完整文章。不会传输用户密码、知乎 Cookie、作品图片。

返回结果必须覆盖原始 ID、符合主题枚举、含完整 14 天且仅引用用户原资料，否则拒绝保存。超时、服务错误或不完整 JSON 会显示错误，不会静默换成本地结果。本地规则与模板在界面中有明确标记。

## 核心逻辑与目录

```text
server.mjs                  HTTP API、账号会话、导入、挑战、搭子、权限隔离
lib/db.mjs                  SQLite 建表、外键、事务
lib/learning.mjs            导入校验、主题识别、AI 适配、14 天课程生成
public/index.html           页面入口
public/app.js               中文交互界面与操作流程
public/style.css            响应式样式
extension/                  Chrome / Edge MV3 收藏导出扩展
tests/                      单元测试与真实 HTTP/SQLite 集成测试
examples/                   人工摄影演示资料
.env.example                可选 AI 与部署配置
```

候选主题至少有 3 条收藏，排除“其他”、已建挑战、已自报在学或暂时不学的主题；按下式排序：

```text
min(100, 20 × log2(收藏数 + 1) + min(已知最早收藏天数, 180) / 9)
```

它是兴趣强度排序分数，不是心理推断的置信概率。原收藏日期未知时只按数量排序。可以在总览把主题标记为“确实还没开始 / 已经在学 / 暂时不学”。每个账号每个主题只创建一个挑战，避免重复点击生成多份。

搭子匹配分数：相同主题 60 分 + 相同阶段 20 分 + 相同学习时段 20 分。仅检索主动参与的账号，不生成虚构搭子。两人需使用同一服务实例；不同电脑各自运行的数据库不会自动互通。搭子只看到主动共享的打卡，无法访问你的收藏目录；关系结束或打卡取消共享后访问立即失效。

## 测试

```sh
node --test tests/*.test.mjs
```

测试包含 URL 校验与去重、兴趣推测边界、14 天选材和时间预算、AI 非法引用/格式、日期跨月、真实 HTTP 注册、账号隔离、导入事务、打卡幂等、未来日期限制、邀请双方确认、共享撤销、反馈权限、屏蔽、持久化及清除授权。AI 测试使用协议级模拟响应；未执行真实付费模型调用。扩展的真实知乎页面兼容性需要在实际登录环境继续验收。

## 多人运行与部署

默认只监听本机 `127.0.0.1`。多人使用需把服务部署到同一台机器，通过 HTTPS 反向代理访问，持久化挂载 `data/`，设置：

```dotenv
HOST=0.0.0.0
PORT=8787
APP_ORIGIN=https://你的域名
COOKIE_SECURE=true
```

开发和本地演示只使用 `http://127.0.0.1:8787`，不要混用 `localhost`，因为写入请求严格校验 `Origin`。如果修改端口，也必须同步修改 `APP_ORIGIN`。

已有密码 scrypt 哈希、HttpOnly/SameSite 会话 Cookie、同源写入校验、参数化 SQL、基本请求限流和私有数据隔离。作品最大 2 MB，保存在 SQLite；适用于本地原型和小规模使用。公开商业运营前仍需完善密码找回、邮件验证、滥用举报处理、持久化/分布式限流、备份清理、对象存储、后台长任务及监控。目前搭子动态是打开页面或点击刷新时拉取，无邮件/推送提醒。

这是可运行 MVP 源码，不是已经完成知乎官方接入审批并经过生产运营验证的产品。

### 轻量挑战模式
默认每天 15 分钟，可选 10、15、20、30、45 分钟；精读、练习和复盘会按时长自动缩短，复盘至少填写 3 个字。


### 吉祥物状态
组件根据当天时间与挑战完成进度，在开心、担心、生气、暴怒四张吉祥物图之间切换。
